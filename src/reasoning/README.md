# 受控问答推理核心

本目录是问答系统的第一阶段推理内核，当前职责是：

1. 从 session 视图读取短期历史、长期记忆、待选择项和实时位置。
2. 把代词、连续追问和带层级限定词的问题解析成独立问题。
3. 输出稳定的 LogicalQuery。
4. 将 LogicalQuery 编译为带资源上限的 ReasoningPlan。
5. 将计划映射到现有的已发布图谱、文本和图片检索服务，并统一证据。
6. 将未找到、歧义等状态转换成可继续对话的用户文案。

当前模块不做以下事情：

- 不直接写 PostgreSQL、图数据库或业务数据。
- 不调用大模型生成答案。
- 不执行自然语言到任意查询语句的拼接。
- 不负责答案措辞、引用标记或 SSE 传输。

执行器复用现有服务：实体链接使用当前领域已发布图谱搜索，图谱动作使用已发布 Neo4j 投影，文本和图片动作使用现有领域检索服务，结果统一经过证据融合。现阶段执行器已经接入 QAService 的答案生成和 SSE 外壳；下一阶段继续完善规则推理与更细粒度的流式轨迹。
