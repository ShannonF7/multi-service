# Stage 25 图谱证据适配器参数修复审计

## 问题

真实 QA 链路已经完成实体召回和对齐，但 Graph 阶段返回 GRAPH 检索失败：spec。原因是 Skill Router 传入的关键字为 query_spec，PublishedGraphGateway.retrieve 却直接读取 kwargs[spec]。

## 修复

- 图谱适配器优先读取 spec，兼容生产 Skill Router 的 query_spec。
- 对缺失 QuerySpec 做安全处理，不影响节点详情本身的证据转换。
- 节点详情和层级候选证据继续只使用当前领域已发布图谱。

## 实际验证到的输入输出

- 输入问题：智能光学实验室在哪里？
- 已识别目标：智能光学实验室。
- 已发布候选：418智能光学实验室。
- 已对齐节点：1668。
- 层级：物理学院 · 南楼 · 四层 · 418智能光学实验室。
- 修复前：检索结果为空，警告为 GRAPH 检索失败：spec。
- 修复后：适配器可以继续执行节点详情，并生成可引用图谱证据。

## 测试

- Stage 24 与 Stage 25 回归测试：3 passed。
- Stage 25 新增测试覆盖 Skill Router 只传 query_spec 的生产调用形态。
- 后续将执行 QA v2 全量测试。

## 边界

- 本修复不改变实体召回算法。
- 本修复不放宽领域隔离或已发布限制。
- 本修复不引入自由 Cypher。
- 本修复不把图谱节点名直接当作答案，答案仍由证据生成链处理。
