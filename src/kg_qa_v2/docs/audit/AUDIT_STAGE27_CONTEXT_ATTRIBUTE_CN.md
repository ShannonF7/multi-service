# Stage 27 审计：上下文属性追问

## 目标

修复用户先询问“智能光学实验室在哪里”，再询问“管理员是谁”时，系统错误复用上一轮位置答案的问题。

## 原因

1. 短问题“管理员是谁”被本地 Router 误判为普通位置问法。
2. 槽位提取没有把上一轮已确认的位置作为隐式目标。
3. 属性意图没有稳定映射为管理员/负责人等字段。
4. 即使当前证据只有位置关系，答案生成仍可能把上一轮位置事实复述为本轮答案。

## 修改内容

- `src/kg_qa_v2/router.py`
  - 将“管理员、负责人、联系人、电话、联系方式、邮箱、名称”等短属性问法纳入快速规则。
  - 避免短属性追问再次调用慢速本地 Router 模型。
- `src/kg_qa_v2/slots.py`
  - 当会话存在最近实体且问题是隐式属性追问时，继承最近已确认实体。
  - 增加管理员、负责人、联系人、电话等属性识别。
  - 让 QuerySpec 的 attribute 与问题类型保持一致。
- `src/kg_qa_v2/understanding.py`
  - fallback + DIRECT_FACT + 最近实体 + 属性问法时，直接使用确定性槽位结果，避免无必要的模型调用。
- `src/kg_qa_v2/answering.py`
  - 当属性证据不存在时，输出“当前领域的已发布图谱中，暂未记录该位置的管理员信息”，禁止复用位置证据。
- `src/kg_qa_v2/service.py`、`src/kg_qa_v2/streaming.py`
  - 接入属性缺失安全答案，并保留正常引用校验链路。

## 输入输出审计

输入：
- 第一轮：智能光学实验室在哪里
- 第二轮：管理员是谁
- 同一 session_id、同一领域

预期 QuerySpec：
- 第一轮 intent=LOCATION，目标为 418 智能光学实验室。
- 第二轮 intent=DIRECT_FACT，attribute=manager，目标继承上一轮实验室。

实际结果：
- 第一轮返回：418智能光学实验室位于物理学院 · 南楼 · 四层。 [E2]
- 第二轮返回：当前领域的已发布图谱中，暂未记录该位置的管理员信息。
- 第二轮不再返回上一轮的位置答案，也没有伪造管理员信息。

## 性能审计

- 第二轮总耗时 147ms，槽位提取 2ms。
